# Mini Cricket - Flutter

A simple Mini Cricket application developed using Flutter.

## Features

- Displays current runs
- Displays remaining balls
- Bat button generates 0–6 runs
- Shows the result of each ball
- Game ends after 6 balls
- Restart button resets the game

## How to Run

1. Install Flutter and Android Studio.
2. Open the project in VS Code or Android Studio.
3. Run:

```bash
flutter pub get
flutter run
